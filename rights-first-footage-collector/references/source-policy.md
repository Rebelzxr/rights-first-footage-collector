# Source policy

Provider terms can change. Check the linked source page and licence again before publication. This project records evidence; it does not provide legal advice.

## Pexels

- API documentation: https://www.pexels.com/api/documentation/
- Licence: https://www.pexels.com/license/
- Record the contributor, media page, provider ID, query, API page and licence URL.
- Respect rate-limit headers. Never rotate keys to evade limits.

## Pixabay

- API documentation: https://pixabay.com/api/docs/
- Content licence: https://pixabay.com/service/license-summary/
- Cache API responses for at least 24 hours.
- Do not perform mass or systematic downloads.
- Record the contributor, media page, provider ID, query, API page and licence URL.

## Openverse and Wikimedia Commons

These sources are not downloaded by the bundled script. They can be reviewed manually for archival stills, maps, diagrams and public-domain works.

- Openverse API: https://api.openverse.org/
- Wikimedia reuse guidance: https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en
- Verify the licence on the original item page.
- Preserve attribution and share-alike requirements when they apply.

## Forbidden default sources

- Do not download random YouTube, TikTok, Instagram, X, film, television, documentary or news footage.
- A public URL is not a reuse licence.
- Use third-party footage only when the rights holder supplies permission or qualified review confirms the intended use.
